# 🛍️ نظام SYVN — نسخة تعمل مباشرة (بدون Google Sheets)

نظام **إدخال بيانات + لوحة تحكم** لمتجر SYVN — ملف HTML واحد يفتح **مباشرة بالنقر المزدوج**، بدون إنترنت، بدون Google، بدون خادم.

## 🚀 التشغيل

1. حمّل ملف `index.html`
2. انقر عليه مرتين ليفتح في المتصفح
3. ابدأ بإدخال الفواتير ✅

> 💾 كل البيانات تُحفظ تلقائيًا داخل المتصفح (localStorage) — تبقى حتى لو أغلقت الصفحة أو أعدت تشغيل الجهاز.

## ✨ المميزات

| الميزة | الوصف |
|--------|-------|
| 📝 نموذج إدخال | منتج، فئة، كمية، سعر، إجمالي تلقائي، زبون، دفع |
| 🔢 رقم فاتورة تلقائي | `SYVN-2026-0001` |
| 📊 لوحة تحكم | مؤشرات + رسوم أشرطة + آخر الفواتير |
| 📁 سجلات | بحث، تعديل، حذف |
| ⬇️ تصدير CSV | يفتح في Excel بالعربية سليمًا (BOM) |
| 💾 نسخة احتياطية | تصدير/استيراد JSON من الإعدادات |
| ⚙️ إعدادات | الفئات، طرق الدفع، العملة — كلها قابلة للتعديل |
| 🧪 بيانات تجريبية | زر لتجربة النظام فورًا |
| 📱 متجاوب | يعمل على الجوال والكمبيوتر |

## ⚠️ ملاحظات مهمة

- البيانات محفوظة **في هذا المتصفح على هذا الجهاز فقط** — للنقل بين الأجهزة استخدم **نسخة احتياطية JSON** من صفحة الإعدادات.
- مسح بيانات المتصفح يعني مسح النظام — خذ نسخة احتياطية بانتظام.
- للنسخة المتصلة بـ Google Sheets (مزامنة سحابية): [syvn-data-entry](https://github.com/Luxorawatches/syvn-data-entry)
